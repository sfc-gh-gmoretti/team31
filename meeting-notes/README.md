# Meeting notes — how these drive suggestions

Drop raw meeting notes into the per-stakeholder files in this directory. Each
file maps to one Aldwych Bank persona from `../index.html`. When asked to
"generate meeting suggestions," read every `*-notes.md` here and synthesize
next-meeting recommendations grounded in what's actually written — do not
conjure detail that isn't in the notes.

## Note to self — generating suggestions

- Read all `*-notes.md`; treat empty sections as "no signal yet," not as facts.
- For each stakeholder with notes, propose: the next meeting's goal, 2-3
  discovery questions, one capability to show, and one takeaway to land.
- Flag stakeholders with no notes as gaps to cover.
- Anchor everything to the deal's Finance-owned outcome: trusted, auditable
  regulatory reporting in days not weeks (FCA / BCBS 239) without ripping out
  Azure.
